DMGraphLib Component Interfaces

What Is This control ?


 

 

This is a simple ActiveX COM control, which allows you to plot two-dimensional data.

The control is able to:

  • Plot a large number of points.
  • Update existing plots on the graph with new data,
  • Replace the old plot with a new plot.
  • Customize at run time multiple plots with individual properties such as name, line and point style, width.
  • Display at runtime its own property pages (double click on the control area or by invoking the ShowProperties method)
  • Show extensive help as a result of the user pressing  Help button on property pages.
  • Set a special TrackMode property to be able to switch between a different modes such as tracking cursor coordinates while moving (left mouse button pressed), get the cursor position by mouse button click, XY-, X-, and Y-zooming, XY-, X-, and Y-panning.
  • Copy in clipboard, print or save as bitmap file the control snapshot.
