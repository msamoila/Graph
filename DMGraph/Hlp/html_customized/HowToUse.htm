DMGraph ActiveX Control  

DMGraphLib Component Interfaces

 

How to use this ActiveX control ?

Each kind of client application has its own way to integrate an ActiveX control. An application created with Microsoft Visual C++, Visual Basic, VB script/java script in HTML pages, .NET applications, Office applications can support the use of ActiveX controls. You can change control's properties during design time or run time. This will affect how the control will plot the data during runtime.

Two files are required to use this control:

  • DMGraph.dll                The DM Graph control's code and data.
  • DMGraph.chm             The help file for this control.

This control needs to be registered in the system registry before use. This is a self registering control. This means that to register the control in the system registry you only need to have an application load the control and call the control’s exported function DllRegisterServer. You can use the REGSVR32 utility or have your setup program do this.

How to use the REGSVR32 utility?

Copy DMGraph.dll to your directory. Open a command prompt (On Windows Vista and later you need to "Run as Administrator"). Change the directory to the one which contains the DLL. Type:

regsvr32 DMGraph.dll


regsvr32 /u DMGraph.dll (Unregister server)
